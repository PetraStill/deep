# Deep Learning — навчальні конспекти

Навчальні конспекти з курсу **Deep Learning for Computer Vision and NLP** від [Neoversity](https://neoversity.ua/).

Конспекти розширені під індивідуальне бачення та пояснення питань, які потребували додаткового розбору.

## Структура

| Тема | Зміст | Матеріали |
|------|-------|-----------|
| **Тема 2** | Логістична регресія | конспект |
| **Тема 3** | Тензори, лінійні шари, функції активації | конспект, ноутбук |
| **Тема 4** | Багатокласова класифікація та регресія в PyTorch | конспект, ноутбук, ДЗ (прогнозування міцності бетону) |
| **Тема 5** | Вступ до комп'ютерного зору та згорткових нейронних мереж (CNN) | конспект |
| **Тема 6** | Transfer Learning і архітектури CNN (ResNet, VGG, EfficientNet…) | конспект, практика ResNet18, ДЗ (Intel Image Classification) |
| **Тема 7** | Object Detection — R-CNN, YOLO | конспект, ноутбук YOLOv9 |
| **Тема 8** | Автоенкодери та детекція аномалій | конспект, ДЗ (Indoor Object Detection) |
| **Тема 9** | Вступ до NLP — підготовка тексту, BoW, TF-IDF, ROC-AUC | конспект, практичний ноутбук |
| **Тема 10** | Word Embeddings — Word2Vec, GloVe, FastText, Doc2Vec | конспект, ДЗ (Email Spam Detection) |
