# Summary: Тема 4 та Тема 5

## Тема 4: Багатокласова класифікація та регресія (табличні дані)

Тема покриває дві фундаментальні задачі supervised learning на **табличних даних**:

1. **Багатокласова класифікація** — передбачення виду пінгвіна (Adelie / Gentoo / Chinstrap) за фізичними ознаками (розмір дзьобу, плавця, маса). Мережа: проста MLP з 2 шарів (4 → 20 → 3), Softmax + CrossEntropyLoss, оптимізатор SGD. Усі дані подаються одразу (без батчів).

2. **Регресія** — прогнозування обсягу продажів магазину (BigMart Sales). Мережа: глибша MLP з 4 шарів (11 → 256 → 128 → 64 → 1), без активації на виході, MSELoss + Adam. Дані подаються **батчами** через Dataset/DataLoader.

Велика теоретична частина присвячена **функціям активації** (Threshold, Linear, Sigmoid, Tanh, ReLU, Leaky ReLU, ELU), проблемі **згасання градієнта** (vanishing gradient) та основам **похідних і chain rule** для backpropagation.

## Тема 5: Комп'ютерний зір та CNN (зображення)

Тема присвячена **класифікації зображень** за допомогою **згорткових нейронних мереж** (CNN):

1. **Зображення як матриці** — Grayscale `[H, W]`, RGB `[3, H, W]`, кольорові канали, роздільна здатність.

2. **CNN-архітектура** — принцип поділу на **base** (згорткова основа: Conv2d + ReLU + MaxPool2d) та **head** (класифікаційна голова: Flatten + Linear + LogSoftmax). Модель: 3 згорткових шари (3 → 32 → 64 → 128) з pooling, потім 2 повнозв'язних шари.

3. **Аугментація** — 9 технік (Resize, Grayscale, Normalize, Random Rotation, Center/Random Crop, Gaussian Blur/Noise, Random Blocks) через `torchvision.transforms`.

4. Задача: класифікація жестів руки (SIGNS dataset, 6 класів, зображення 64×64), CrossEntropyLoss + Adam, balanced_accuracy_score.

## Головні спільності

| Аспект | Спільне |
|---|---|
| **Фреймворк** | Обидві теми використовують PyTorch (`nn.Module`, `torch.Tensor`, autograd) |
| **Пайплайн навчання** | Ідентичний цикл: `forward → loss → zero_grad → backward → step` |
| **Dataset / DataLoader** | Обидві теми використовують абстракції PyTorch для подачі даних (`__len__`, `__getitem__`, батчева обробка) |
| **Train / Eval режими** | `model.train()` + `model.eval()` + `torch.no_grad()` — однакова логіка розділення фаз |
| **Функція втрат** | Для класифікації в обох темах — CrossEntropyLoss |
| **Активація** | ReLU як стандарт для прихованих шарів; Softmax / LogSoftmax на виході для класифікації |
| **Діагностика** | Графіки train vs validation (loss + метрика) для виявлення overfitting/underfitting |
| **Preprocessing** | Нормалізація / стандартизація вхідних даних перед подачею в мережу |

## Головні відмінності

| Аспект | Тема 4 (табличні дані) | Тема 5 (зображення) |
|---|---|---|
| **Тип вхідних даних** | CSV-таблиці, вектор числових ознак `[N, features]` | Зображення (JPG), тензор `[N, C, H, W]` |
| **Архітектура** | MLP — тільки повнозв'язні шари (`nn.Linear`) | CNN — згорткові шари (`nn.Conv2d`) + pooling + повнозв'язні |
| **Ключова ідея** | Кожен нейрон бачить **всі** ознаки | Кожен фільтр бачить **локальну ділянку** (weight sharing, інваріантність до зсувів) |
| **Підготовка даних** | StandardScaler, TargetEncoder, SimpleImputer (sklearn) | `torchvision.transforms`: Resize, ToTensor, Normalize |
| **Аугментація** | Не застосовується | Критично важлива: Flip, Rotation, Crop, Blur, Noise |
| **Бібліотеки CV** | Не потрібні | OpenCV (`cv2`), Pillow (`PIL`), `torchvision` |
| **Теоретичний фокус** | Функції активації, vanishing gradient, похідні, chain rule | Операція згортки, фільтри/ядра, stride, padding, pooling |
| **Задачі** | Класифікація **і** регресія | Тільки класифікація (зображень) |
| **Складність моделі** | Прості MLP (2–4 шари, десятки-сотні нейронів) | CNN з ієрархією ознак (краї → текстури → форми) |
| **Метрика** | Accuracy / RMSE | Balanced Accuracy |
| **GPU** | Не акцентується | Явна підтримка CUDA (`.to(device)`, `.cuda()`) |

## Ключовий зв'язок між темами

Тема 5 **будується поверх** теми 4. Усе, що вивчено в темі 4 — цикл навчання, loss-функції, оптимізатори, Dataset/DataLoader, train/eval режими, діагностика графіків — **повністю зберігається**. CNN додає новий тип шарів (Conv2d, Pooling) замість чисто повнозв'язних, і новий тип підготовки даних (трансформації зображень замість табличного preprocessing). Класифікаційна голова CNN — це фактично та сама MLP з теми 4, яка отримує на вхід не «сирі» ознаки, а ознаки, витягнуті згортковими шарами.
