## ЧАСТИНА 0. ТЕОРІЯ — ЩО МИ БУДУЄМО І НАВІЩО

### Що таке логістична регресія?

Логістична регресія — це алгоритм, який відповідає на запитання типу **«так чи ні»**: «Пасажир вижив? Так чи ні?», «Лист — спам? Так чи ні?».

Хоча це **статистичний** алгоритм, він може бути зображений у вигляді **нейронної мережі** — тобто ланцюжка обчислень.

### Як виглядає ця «мережа»?

Уяви, що ти — кухар. До тебе приходять інгредієнти (x1, x2, x3...). Кожен інгредієнт ти кладеш у різній кількості (w0, w1, w2...). Все перемішуєш (+) і додаєш трішки солі (b). Потім пропускаєш через фільтр (сигмоїда), і отримуєш відповідь — число від 0 до 1.

```
x1 ──(×w0)──┐
x2 ──(×w1)──┤
x3 ──(×w2)──┼──[ + b ]──[ сигмоїда ]──► y_head (0.9) ──► якщо > 0.5 → "1: Transported"
x4 ──(×w3)──┤
xn ──(×wn)──┘
```

### Розшифровка всіх скорочень і символів

| Символ / Скорочення | Що означає | Простими словами |
|---|---|---|
| `x1, x2, ... xn` | вхідні ознаки (features) | дані про пасажира — вік, витрати тощо |
| `X_train` | матриця всіх вхідних ознак тренувального набору | таблиця з усіма пасажирами та їхніми даними |
| `w0, w1, ... wn` | **weights** — ваги | наскільки важлива кожна ознака |
| `b` | **bias** — зміщення | поправка, яка допомагає моделі краще підібрати лінію |
| `z` | проміжний результат = w·X + b | просто число, яке ще не є ймовірністю |
| `y_head` або `ŷ` | передбачення (prediction) | відповідь моделі — число від 0 до 1 |
| `y` або `y_true` | реальна відповідь із датасету | правильна відповідь (0 або 1) |
| `sigmoid` | функція активації | перетворює будь-яке число в число між 0 і 1 |
| `TARGET` | цільова змінна | те, що ми хочемо передбачити — `Transported` |
| `EDA` | Exploratory Data Analysis | дослідження даних — дивимось, що у нас є |
| `m` | кількість прикладів у тренувальному наборі | кількість рядків у таблиці |
| `α` (альфа) | learning rate — швидкість навчання | як великий крок робить модель під час навчання |
| `J(w,b)` або `cost` | функція втрат (loss function) | наскільки сильно модель помиляється |
| `BCE` | Binary Cross-Entropy | формула для вимірювання помилки в задачах так/ні |
| `∂J/∂W` | похідна функції втрат по вагах | в який бік і наскільки треба змінити ваги |
| `df` | DataFrame | таблиця даних у Python (pandas) |
| `imputer` | заповнювач пропусків | інструмент, що замінює порожні клітинки числами |
| `One-hot encoding` | кодування категорій | перетворення слів (наприклад, "Europa") на нулі та одиниці |
| `train_test_split` | розбивка даних | ділимо дані на «для навчання» і «для перевірки» |
| `accuracy` | точність | відсоток правильних відповідей моделі |
| `gradient` | градієнт | напрямок, у якому найшвидше зростає помилка (ми йдемо в протилежний бік) |

```python
services_features = cont_features[1:]  # всі числові, крім Age (Age починається з індексу 0)

for feature in services_features:
    df[f'used_{feature}'] = df.loc[:, feature].apply(lambda x: 1 if x > 0 else 0)
```

**Пояснення:**

- `cont_features[1:]` — беремо список числових ознак починаючи з 2-го елемента (індекс 1), тобто пропускаємо `Age`. Квадратні дужки `[1:]` — це зріз (slice) списку.

- `df[f'used_{feature}']` — створюємо нову колонку. `f'...'` — це f-рядок: Python автоматично підставляє значення змінної всередину рядка. Наприклад, `f'used_{feature}'` стає `'used_RoomService'`.

## ЧАСТИНА 4. ОБРОБКА ПРОПУЩЕНИХ ЗНАЧЕНЬ

### Крок 11. Заповнення пропущених числових значень медіаною

**Навіщо:** модель не може працювати з порожніми клітинками. Медіана — «середнє» число при сортуванні — краще за середнє арифметичне, бо менш чутлива до викидів.

```python
imputer_cols = ["Age", "FoodCourt", "ShoppingMall", "Spa", "VRDeck", "RoomService"]
imputer = SimpleImputer(strategy='median')
imputer.fit(df[imputer_cols])
df[imputer_cols] = imputer.transform(df[imputer_cols])
```

**Пояснення:**

- `imputer_cols = [...]` — список числових колонок із пропусками.
- `SimpleImputer(strategy='median')` — створюємо об'єкт-заповнювач. `strategy='median'` — стратегія заповнення — медіаною. Можна також `'mean'` (середнє) або `'most_frequent'` (найчастіше).
- `.fit(df[imputer_cols])` — `imputer` **вивчає** медіану кожної колонки (запам'ятовує, яке число підставляти).
- `.transform(df[imputer_cols])` — **застосовує** заповнення: замінює порожні клітинки вивченими медіанами.
- `df[imputer_cols] = ...` — перезаписуємо ці колонки в таблиці вже заповненими значеннями.

### Крок 12. Заповнення пропущених значень категоріальних змінних фіктивними значеннями

**Навіщо:** для текстових категорій медіана не підходить. Якщо пасажир не вказав планету — можливо, це важлива інформація сама по собі. Тому ставимо вигадану назву.

```python
df["HomePlanet"].fillna('Gallifrey', inplace=True)
df["Destination"].fillna('Skaro', inplace=True)
```

**Пояснення:**

- `.fillna(...)` — замінює всі `NaN` (Not a Number — порожнє значення) на вказане значення.
- `'Gallifrey'` і `'Skaro'` — вигадані назви планет (з Doctor Who!), які не зустрічаються в реальних даних → модель розумітиме, що це «невідома планета».
- `inplace=True` — змінюємо таблицю **прямо на місці**, не створюючи нову копію. Без цього параметру зміни не збережуться в `df`.

## ЧАСТИНА 6. РОЗБИВКА ДАНИХ НА ТРЕНУВАЛЬНІ ТА ТЕСТОВІ

### Крок 19. Train/Test Split

**Навіщо:** ми навчаємо модель на одних даних, а перевіряємо на інших — щоб упевнитись, що модель навчилась загальним закономірностям, а не просто «вивчила напам'ять» тренувальні приклади.

```python
X = df.drop(TARGET, axis=1)
y = df[TARGET]

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42, test_size=0.33, stratify=y)
```

**Пояснення:**

- `X = df.drop(TARGET, axis=1)` — вхідні ознаки: вся таблиця **без** колонки `Transported`.
- `y = df[TARGET]` — цільова змінна: **тільки** колонка `Transported`.
- `train_test_split(X, y, ...)` — розбиває дані на 4 частини:
  - `X_train` — ознаки для навчання
  - `X_test` — ознаки для перевірки
  - `y_train` — правильні відповіді для навчання
  - `y_test` — правильні відповіді для перевірки
- `random_state=42` — фіксуємо «випадковість», щоб щоразу отримувати однаковий результат. Число 42 — традиційний вибір (можна будь-яке).
- `test_size=0.33` — 33% даних іде в тест, 67% — в тренування.
- `stratify=y` — гарантує, що в обох наборах співвідношення True/False у `Transported` буде однаковим (збалансованим).

### Крок 20. Транспонування матриць

**Навіщо:** наша реалізація логістичної регресії очікує дані у форматі [кількість ознак × кількість прикладів], а не навпаки. Транспонування міняє рядки та стовпці місцями.

```python
x_train = X_train.T
x_test = X_test.T
y_train = np.expand_dims(y_train.T, 0)
y_test = np.expand_dims(y_test.T, 0)

print('X train size', x_train.shape)
print('X test size', x_test.shape)
print('y train size', y_train.shape)
print('y test size', y_test.shape)
```

**Пояснення:**

- `.T` — транспонування: матриця перевертається. Рядки стають стовпцями, стовпці — рядками.
- `np.expand_dims(y_train.T, 0)` — додає зайвий вимір до вектора `y`, щоб він став матрицею розмірності `[1, m]` (один рядок, `m` стовпців). `0` означає «додати вимір спочатку».
- Після цього кроку `x_train.shape` буде `[кількість_ознак, кількість_прикладів]`.

## ЧАСТИНА 7. БУДУЄМО МОДЕЛЬ — ВСІ ФУНКЦІЇ

### Крок 21. Функція ініціалізації ваг

**Навіщо:** перед навчанням модель має мати якісь початкові ваги. Ми ставимо невеликі рівні значення.

```python
def initialize_weights_and_bias(dimension):
    w = np.full((dimension, 1), 0.01)
    b = 0.0
    return w, b
```

**Пояснення:**

- `def` — оголошення функції.
- `dimension` — вхідний параметр: кількість ознак (кількість стовпців у нашій таблиці вхідних даних).
- `np.full((dimension, 1), 0.01)` — створює матрицю розмірністю `[dimension, 1]` (стовпець) і заповнює її значенням `0.01`. Тобто всі ваги спочатку однакові і маленькі.
- `b = 0.0` — зміщення починається з нуля.
- `return w, b` — функція повертає обидва значення.

### Крок 22. Функція сигмоїди

**Навіщо:** перетворює будь-яке число (навіть дуже велике або від'ємне) на значення між 0 і 1. Це і є наша «ймовірність».

```python
def sigmoid(z):
    y_head = 1 / (1 + np.exp(-z))
    return y_head
```

**Пояснення:**

- `np.exp(-z)` — обчислює `e^(-z)`, де `e ≈ 2.718` (число Ейлера).
- Формула `1 / (1 + e^(-z))`: якщо `z` дуже велике → результат близький до 1; якщо `z` дуже мале (від'ємне) → результат близький до 0; якщо `z = 0` → результат = 0.5.
- `y_head` — передбачена ймовірність. «Head» від `ŷ` (читається «y hat» = «y з капелюшком»).

### Крок 23. Пряме і зворотне розповсюдження (Forward + Backward Pass)

**Пряме розповсюдження (Forward Pass)** — передаємо дані через мережу і отримуємо передбачення і помилку.

**Зворотне розповсюдження (Backward Pass)** — рахуємо, як змінити ваги, щоб помилка зменшилась.

```python
def forward_backward_propagation(w, b, x_train, y_train, eps=1e-5):

    # --- ПРЯМЕ РОЗПОВСЮДЖЕННЯ ---
    z = np.dot(w.T, x_train) + b
    y_head = sigmoid(z)
    loss = -1 * y_train * np.log(y_head + eps) - (1 - y_train) * np.log(1 - y_head + eps)
    cost = (np.sum(loss)) / x_train.shape[1]

    # --- ЗВОРОТНЕ РОЗПОВСЮДЖЕННЯ ---
    derivative_weight = (np.dot(x_train, ((y_head - y_train).T))) / x_train.shape[1]
    derivative_bias = np.sum(y_head - y_train) / x_train.shape[1]

    gradients = {"derivative_weight": derivative_weight, "derivative_bias": derivative_bias}
    return cost, gradients
```

**Детальне пояснення кожного рядка:**

**Пряме розповсюдження:**

- `z = np.dot(w.T, x_train) + b`
  - `np.dot(w.T, x_train)` — множення матриць: транспонований вектор ваг на матрицю ознак. Це реалізація формули `z = w^T · X`.
  - `w.T` — транспонований вектор ваг (рядок замість стовпця).
  - `+ b` — додаємо зміщення.
  - Результат `z` — вектор: одне число для кожного пасажира.

  **Як це виглядає наочно** (уяви 3 пасажири і 4 ознаки):

  Матриця ознак `x_train` [ознаки × пасажири]:
  ```
                    Пасажир1  Пасажир2  Пасажир3
  Age                   39        24        58
  CryoSleep              0         1         0
  RoomService            0       150       200
  VIP                    0         0         1
  ```

  Вектор ваг `w` [ознаки × 1] — спочатку всі однакові:
  ```
  Age          0.01
  CryoSleep    0.01
  RoomService  0.01
  VIP          0.01
  ```

  `w.T` — вектор ваг, покладений горизонтально [1 × ознаки]:
  ```
               Age   CryoSleep  RoomService  VIP
  w.T →      [0.01,    0.01,      0.01,     0.01]
  ```

  Множимо `w.T` на кожен стовпець `x_train` — отримуємо одне `z` на пасажира:
  ```
  z_пасажир1 = 0.01×39 + 0.01×0 + 0.01×0   + 0.01×0 = 0.39
  z_пасажир2 = 0.01×24 + 0.01×1 + 0.01×150 + 0.01×0 = 1.75
  z_пасажир3 = 0.01×58 + 0.01×0 + 0.01×200 + 0.01×1 = 2.59
  ```

  Додаємо `b = 0` (поки нічого не змінює): `z = [0.39, 1.75, 2.59]`

  Після сигмоїди отримуємо ймовірності:
  ```
  sigmoid(0.39) = 0.60  →  60% що перенесений
  sigmoid(1.75) = 0.85  →  85% що перенесений
  sigmoid(2.59) = 0.93  →  93% що перенесений
  ```
  Після навчання ваги перестануть бути однаковими — кожна ознака отримає своє значення (наприклад, `CryoSleep` отримає більшу вагу, бо вона найбільше корелює з ціллю).

- `y_head = sigmoid(z)` — передаємо `z` через сигмоїду. Отримуємо ймовірності від 0 до 1 для кожного пасажира.

- `loss = -1 * y_train * np.log(y_head + eps) - (1 - y_train) * np.log(1 - y_head + eps)`
  - Це **бінарна крос-ентропія** для кожного прикладу окремо.
  - `np.log(...)` — натуральний логарифм.
  - `eps=1e-5` — дуже маленьке число (0.00001), яке додаємо, щоб уникнути `log(0)` (логарифм нуля не існує → помилка в програмі).
  - Якщо правильна відповідь `y=1`, а модель передбачила `y_head=0.9` → втрата мала. Якщо модель передбачила `y_head=0.1` → втрата велика.

- `cost = np.sum(loss) / x_train.shape[1]`
  - `np.sum(loss)` — сумуємо втрати по всіх прикладах.
  - `x_train.shape[1]` — кількість прикладів (стовпців у `x_train`). Ділимо, щоб отримати **середню** втрату — незалежну від кількості прикладів.

**Зворотне розповсюдження:**

- `derivative_weight = (np.dot(x_train, ((y_head - y_train).T))) / x_train.shape[1]`
  - Це формула `∂J/∂W = (1/m) · X · (ŷ - y)^T` у коді.
  - `y_head - y_train` — різниця між передбаченням і правильною відповіддю (помилка).
  - `np.dot(x_train, ...)` — матричне множення ознак на помилку.
  - Результат — градієнт по вагах: наскільки і в якому напрямку змінити `w`.

- `derivative_bias = np.sum(y_head - y_train) / x_train.shape[1]`
  - Це формула `∂J/∂b = (1/m) · Σ(ŷ - y)`.
  - Сумуємо всі помилки і ділимо на кількість прикладів.
  - Результат — градієнт по зміщенню `b`.

- `gradients = {"derivative_weight": ..., "derivative_bias": ...}` — зберігаємо обидва градієнти у словнику (dict), щоб зручно повертати з функції.

### Крок 24. Функція оновлення ваг (навчання)

```python
def update(w, b, x_train, y_train, learning_rate, number_of_iterarion):
    cost_list = []
    index = []

    for i in range(number_of_iterarion):
        cost, gradients = forward_backward_propagation(w, b, x_train, y_train)
        cost_list.append(cost)
        index.append(i)

        w = w - learning_rate * gradients["derivative_weight"]
        b = b - learning_rate * gradients["derivative_bias"]

    parameters = {"weight": w, "bias": b}
    plt.plot(index, cost_list)
    plt.xticks(index, rotation='vertical')
    plt.xlabel("Number of Iterarion")
    plt.ylabel("Cost")
    plt.show()
    return parameters, gradients, cost_list
```

**Пояснення:**

- `cost_list = []` і `index = []` — порожні списки для збереження значень функції втрат і номерів епох (для графіка).
- `for i in range(number_of_iterarion):` — цикл на задану кількість ітерацій (епох). Кожна **ітерація** = один прохід по всіх даних.
- `cost, gradients = forward_backward_propagation(...)` — виконуємо прямий і зворотний прохід, отримуємо значення функції втрат і градієнтів.
- `cost_list.append(cost)` — додаємо поточну втрату до списку (щоб потім намалювати графік).
- `w = w - learning_rate * gradients["derivative_weight"]` — **оновлення ваги**: нова вага = стара вага - крок × градієнт. Це реалізація формули `w := w - α · ∂J/∂W`. Ми рухаємось **проти** градієнта, тому що хочемо мінімізувати помилку.
- `learning_rate` (**α, альфа**) — наскільки великий крок ми робимо. Якщо замалий → навчання повільне. Якщо завеликий → модель «перескакує» мінімум і не навчається.
- `b = b - learning_rate * gradients["derivative_bias"]` — аналогічно оновлюємо зміщення.
- `parameters = {"weight": w, "bias": b}` — зберігаємо фінальні ваги у словнику.
- `plt.plot(index, cost_list)` — малюємо графік спаду функції втрат.

### Крок 25. Функція передбачення

```python
def predict(w, b, x_test):
    z = sigmoid(np.dot(w.T, x_test) + b)
    Y_prediction = np.zeros((1, x_test.shape[1]))
    for i in range(z.shape[1]):
        if z[0, i] <= 0.5:
            Y_prediction[0, i] = 0
        else:
            Y_prediction[0, i] = 1
    return Y_prediction
```

**Пояснення:**

- `z = sigmoid(np.dot(w.T, x_test) + b)` — прямий прохід з **навченими** вагами: отримуємо ймовірності для тестових даних.
- `Y_prediction = np.zeros((1, x_test.shape[1]))` — створюємо масив нулів: один рядок, стільки стовпців, скільки тестових прикладів. Сюди запишемо передбачення.
- `for i in range(z.shape[1]):` — перебираємо кожен приклад.
- `if z[0, i] <= 0.5:` — якщо ймовірність менша або рівна 0.5 → передбачаємо **0** (не перенесений). Інакше → **1** (перенесений).
- Це реалізація правила: якщо `y_head > 0.5` → клас 1, інакше клас 0.

### Крок 26. Фінальна функція — збираємо все разом

```python
def logistic_regression(x_train, y_train, x_test, y_test, learning_rate, num_iterations):
    dimension = x_train.shape[0]
    w, b = initialize_weights_and_bias(dimension)

    parameters, gradients, cost_list = update(w, b, x_train, y_train, learning_rate, num_iterations)

    y_prediction_test = predict(parameters["weight"], parameters["bias"], x_test)
    y_prediction_train = predict(parameters["weight"], parameters["bias"], x_train)

    print("train accuracy: {} %".format(100 - np.mean(np.abs(y_prediction_train - y_train)) * 100))
    print("test accuracy: {} %".format(100 - np.mean(np.abs(y_prediction_test - y_test)) * 100))
```

**Пояснення кожного кроку:**

1. `dimension = x_train.shape[0]` — кількість ознак (рядків у транспонованій матриці). `shape[0]` — перший вимір.
2. `w, b = initialize_weights_and_bias(dimension)` — ініціалізуємо ваги та зміщення.
3. `parameters, gradients, cost_list = update(...)` — навчаємо модель: `num_iterations` разів оновлюємо ваги.
4. `y_prediction_test = predict(...)` — передбачаємо відповіді на **тестових** даних.
5. `y_prediction_train = predict(...)` — передбачаємо відповіді на **тренувальних** даних.
6. `100 - np.mean(np.abs(y_prediction_train - y_train)) * 100` — обчислення точності:
   - `y_prediction_train - y_train` — різниця між передбаченням і правильною відповіддю.
   - `np.abs(...)` — беремо модуль (без знаку мінус).
   - `np.mean(...)` — середнє значення (частка помилок).
   - `100 - ... * 100` — перетворюємо частку помилок на відсоток точності.

## ЧАСТИНА 9. ЗВОРОТНЕ РОЗПОВСЮДЖЕННЯ — МАТЕМАТИКА

**Що таке зворотне розповсюдження (backpropagation)?**

Це процес оновлення ваг моделі на основі похідних (градієнтів) функції втрат.

**Формула оновлення ваги:**

```
w := w - α · ∂J(w,b) / ∂(w,b)
```

- `w :=` — нове значення w (`:=` означає «присвоїти»)
- `α` (альфа) — learning rate, швидкість навчання
- `∂J/∂(w,b)` — похідна функції втрат J по вагах — показує, в якому напрямку зростає помилка

**Формули похідних:**

```
∂J/∂W = (1/m) · X · (ŷ - y)ᵀ

∂J/∂b = (1/m) · Σ(ŷ - y)   (сума по всіх прикладах від i=1 до m)
```

- `m` — кількість навчальних прикладів
- `X` — матриця вхідних ознак
- `ŷ - y` — різниця між передбаченням і правильною відповіддю
- `ᵀ` — транспонування
- `Σ` — сума (грецька літера сигма, означає «скласти все разом»)

**Ідея просто:** уяви, що ти стоїш на горі (висока помилка) і хочеш спуститись у долину (низька помилка). Градієнт показує, в якому напрямку гора стає вищою — ти йдеш **у протилежний бік**. Розмір кроку — це твій `learning_rate`.
